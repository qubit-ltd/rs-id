# rs-id 0.3 implementation plan

1. Add deterministic concurrent overflow regression tests for classic
   Snowflake and Sonyflake, plus a Sonyflake test that rejects logical future
   timestamps. Run them against 0.2.4 and record the failures.
2. Refactor both generators to `parking_lot::Mutex<Option<TimeSlice>>`, use the
   startup fence, and reserve every timestamp/sequence pair under the mutex.
   Update existing boundary tests and add restart and panic-recovery coverage.
3. Add failing tests for the Qubit layout codec. Replace
   `QubitSnowflakeBuilder` with `QubitSnowflakeLayout`, add
   `QubitSnowflakeParts`, and expose configuration-independent `decode`.
4. Remove the obsolete poisoned-lock error, update public exports and all call
   sites, and document probabilistic uniqueness for Mica UUID-like IDs.
5. Align English and Chinese READMEs with the 0.3 API and exact uniqueness,
   ownership, restart, rollback, and blocking semantics. Bump the crate and
   lockfile versions to 0.3.0.
6. Run focused tests, `./align-ci.sh`, and `./ci-check.sh`; inspect the final
   diff without committing it.
